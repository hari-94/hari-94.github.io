Personal portfolio site for Hari Prasath Ulaganathan — data analyst working in SQL, dbt/Snowflake pipelines and BI reporting.

Live at **https://hari-94.github.io**

## Contents

| File | Purpose |
| --- | --- |
| `index.html` | The whole site — a single self-contained page (styles inline, no build step) |
| `hari.jpg` | Portrait used in the header |
| `resume.pdf` | Résumé linked from the page |
| `resume.typ` | Résumé source (Typst, XCharter font) |
| `bgv-scheduling-flow.gif` | Animated walkthrough in the scheduling case study |
| `bgv-scheduling-still.png` | Still shown instead of the GIF when motion is reduced |

## Editing

There is no build step and no dependencies. Open `index.html`, edit, commit to `main`, and GitHub Pages redeploys within a minute.
